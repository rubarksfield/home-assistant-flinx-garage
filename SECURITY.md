# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/rubarksfield/home-assistant-flinx-garage/security/advisories/new), rather than a public issue. Use fabricated examples and do not attach working credentials, device keys or household captures.

The latest stable fork release receives security fixes. Older and upstream releases must be assessed separately. See [security and privacy notes](docs/security.md) for transport limitations and publication checks.
